Home of **[Slack of the Rings](slack-of-the-rings/)**: a Slack bot with ten slash commands that answer your team with a fitting line from Middle-earth.

| You type | Who answers | What they say |
|---|---|---|
| `/gandalf merge without tests` | 🧙‍♂️ Gandalf | “You shall not pass!” |
| `/gandalf deployed successfully` | 🧙‍♂️ Gandalf | “Breathe the free air again, my friend.” |
| `/frodo feeling overwhelmed` | 💍 Frodo | “It's such a weight to carry.” |
| `/legolas closed 10 tickets` | 🪓 Gimli, cutting in on Legolas | “That still only counts as one!” |
| `/gollum coffee` | 🐟 Gollum | We wants it, we needs it! Must have the **coffee**… raw and wriggling! |

- **Runs on your own computer.** No server, no public URL, no AI service, nothing paid.
- **Five minutes to set up.** One link creates the Slack app with every command registered.
- **Film quotes from [The One API](https://the-one-api.dev)**, optionally. Without a token the bot uses the lines it ships with.
- **Rules, not guesses.** Each character knows a set of situations and answers from hand-picked lines that were checked for speaker and wording.

## Get started

Click **Code → Download ZIP** above (or clone the repository), then follow the **[project README](slack-of-the-rings/README.md)**. It covers setup, every command, how the bot chooses its replies, and how The One API is used.
