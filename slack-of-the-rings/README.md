# Slack of the Rings: the bot

This folder is the bot itself. The full guide is the **[README at the top of the repository](../README.md)**: installation, every command, how The One API is used, and how the code is put together.

To start it from a terminal in this folder:

```bash
npm install      # first time only
npm run setup    # first time only: asks for your Slack tokens
npm start
```

On a Mac you can double-click `start.command` instead.

Every situation the characters know is listed in [COMMANDS.md](COMMANDS.md).
